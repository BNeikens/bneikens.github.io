# Neikens Website Refresh

This package is ready to copy into the root of the `bneikens.github.io` repository.

## Main updates

- Replaced the construction-page hero with the supplied industrial electrical banner.
- Routed bid/contact buttons to `Bids@NeikensEC.com`.
- Added industrial, municipal, water, wastewater, controls, generator, and distribution service copy.
- Replaced template/demo projects and client logos with actual capability content.
- Added editable team cards for Bonnie Neikens, Jon-Erik Neikens, John Brooks, Sam Tessier, and Nick Vanamburgh.
- Added SEO titles, descriptions, social sharing tags, canonical URLs, LocalBusiness/Electrician structured data, FAQ structured data, robots.txt, sitemap.xml, descriptive headings, alt text, and local service-area content.
- Removed the PHP contact form because GitHub Pages does not execute PHP. Website contact is now email-only through `Bids@NeikensEC.com`.

## Before publishing

1. Review `_config.yml`, especially the email address, service area, team positions, and bios.
2. Replace the placeholder team SVGs in `img/team/` with actual employee portraits. Update the `image:` filenames in `_config.yml` if the file extensions change.
3. Open the repository in VS Code and copy all package files over the matching paths.
4. Commit to a test branch, push, and preview before merging to `main`.

## Suggested photo dimensions

Use square portrait images at least 800 × 800 pixels. Crop faces consistently and optimize each file to approximately 150–350 KB.
